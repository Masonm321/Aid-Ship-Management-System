
# Aid Ship Management System

**JavaFX Desktop Application | Java | Object-Oriented Programming | CSV Data Management**

## Project Overview

The Aid Ship Management System is a Java desktop application developed to organize and manage aid-ship records through an interactive graphical interface.

The project demonstrates object-oriented software design, user interface development, file-based data management, input validation, and application debugging.

## Key Features

- **Login Interface:** Provides a user authentication screen with input validation and error feedback.
- **Ship Management:** View, search, sort, and delete aid-ship records through a graphical interface.
- **CSV Data Handling:** Uses CSV files to organize and manage application data.
- **Object-Oriented Architecture:** Separates application responsibilities across model classes, controllers, and interfaces.
- **Interactive GUI:** Uses JavaFX and FXML to build application screens and manage user interactions.

## Technologies Used

## Software Architecture

The application organizes functionality into several components:

- **AidShipApplication:** Application entry point and JavaFX initialization.
- **LoginScreenController:** Handles login interactions and validation.
- **MainScreenController:** Coordinates ship-management operations.
- **AidShipManager:** Organizes ship records and management functionality.
- **Model Classes:** Represent application entities and their behavior.
- **Interfaces:** Define shared capabilities and support modular design.
